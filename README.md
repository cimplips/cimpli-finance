# Keuangan Prima Pro

Starter production-ready Flutter.

## Sudah tersedia
- SQLite database lokal
- Keuangan Pribadi, Kantor, Rumah
- Tambah akun keuangan
- Dashboard ala mobile banking
- Pemasukan, pengeluaran, saldo
- Riwayat transaksi
- Kategori transaksi
- Anggaran bulanan
- PIN lokal
- GitHub Actions APK/AAB

## Jalankan
```bash
flutter create . --platforms=android --org com.keuanganprima
flutter pub get
flutter run
```
